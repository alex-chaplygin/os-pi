#########################################
Библиотека параллельного программирования
#########################################

Базовой единицей многозадачности является **поток** (thread). Поток представляет собой функцию, которая выполняется параллельно (в режиме кооперативной многозадачности) основному потоку выполнения. Функция потока может добровольно передавать управление другим потокам с помощью явного вызова уступки (следующий поток выбирается планировщиком автоматически). После завершения функции поток автоматически удаляется. В системе всегда существует по крайней мере один поток — главный.

Потоки идентифицируются целыми числами от 0 до ``MAX_THREADS - 1`` (где 0 — главный поток). Всего система поддерживает до 64 одновременно существующих потоков.

*********************
 Управление потоками
*********************

Создание потока: ``thread-spawn``
=================================

``(thread-spawn <функция>)``

Функция ``thread-spawn`` принимает функцию без аргументов (лямбда-выражение) и запускает ее как независимый поток, добавляя его в кольцевую очередь готовых к выполнению задач:

.. code:: common-lisp

   (let ((my-thread (thread-spawn #'(lambda () (print "Thread running"))))) ;; поток создан и поставлен в очередь
     ...
     )

Возвращает уникальный числовой идентификатор созданного потока (Lisp-число). При исчерпании свободных структур потоков (достигнут лимит в 64 потока) функция сигнализирует об ошибке нехватки памяти (``"Error: out of memory: threads"``).

Кооперативная уступка: ``thread-yield``
=======================================

``(thread-yield)``

При кооперативном переключении долго выполняющиеся вычисления должны периодически уступать процессор другим потокам с помощью ``thread-yield``:

.. code:: common-lisp

   (thread-spawn
     #'(lambda ()
        (for i 1 5
          (print "Step" i)
          (thread-yield)))) ;; передача управления другим активным потокам

Функция сохраняет контекст текущего потока и переключает выполнение на следующий готовый поток в кольцевой очереди. Если в очереди активных задач остался только один поток, функция возвращает управление немедленно без переключения контекста.

Ожидание завершения: ``thread-wait``
====================================

``(thread-wait <id потока>)``

Функция ``thread-wait`` приостанавливает вызывающий поток до тех пор, пока не завершится целевой поток с указанным идентификатором ``id``, и возвращает вычисленный результат выполнения его функции.

.. code:: common-lisp

   (let ((calc-thread (thread-spawn
                       #'(lambda ()
                          (thread-yield)
                          42))))
     (let ((answer (thread-wait calc-thread)))
       (print answer)))

.. note::
   В текущей реализации функция находится в разработке (заглушка). В дальнейшем ее вызов в главном потоке будет запрещен во избежание взаимных блокировок.

Принудительная остановка: ``thread-kill``
=========================================

``(thread-kill <id потока>)``

Функция ``thread-kill`` принудительно завершает выполнение потока с указанным идентификатором ``id``, исключает его из активной очереди и возвращает его структуру в пул свободных слотов.

.. code:: common-lisp

   (let ((worker (thread-spawn #'(lambda () (loop (print "working..."))))))
     ;; ...
     (thread-kill worker)) ;; принудительное завершение рабочего потока

Особенности работы:

* **Освобождение неактивного потока:** если завершается поток, не выполняющийся на процессоре прямо сейчас, он удаляется из очереди активных задач без переключения контекста текущего потока.
* **Освобождение текущего потока:** если завершается текущий исполняемый поток (``current_thread``), он исключается из очереди, и управление немедленно передается следующему активному потоку.
* **Главный поток защищен от удаления:** главный поток создается при инициализации системы по умолчанию. Попытка вызвать ``thread-kill`` для главного потока (``id = 0``) вызывает ошибку (``"thread_kill: cannot kill main thread"``).
