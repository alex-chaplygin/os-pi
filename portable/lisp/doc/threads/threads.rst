########################################
Библиотека паралельного программирования
########################################

Базовой единицей многозадачности является **поток** (thread). Поток представляет собой функцию, которая запускается параллельно основному потоку выполнения. Функция потока может передавать управление другим потокам (выбирается автоматически. После завершения функции поток автоматически удаляется. Всегда существует по крайней мере один поток (главный).

*********************
 Управление потоками
*********************

Создание потока: ``thread-spawn``
=================================

(thread-spawn <функция>) возвращает уникальный идентификатор потока.

Функция ``thread-spawn`` принимает функцию без аргументов и запускает ее как независимый поток:

.. code:: common-lisp

   (let ((my-thread (thread-spawn  #'(lambda () (print "Thread running"))))) ;; поток автоматически запустится
     ...
     )

Кооперативная уступка: ``thread-yield``
=======================================

(thread-yield)

При кооперативном переключении долго выполняющиеся вычисления должны периодически уступать процессор другим потокам с помощью
``thread-yield``:

.. code:: common-lisp

   (thread-spawn
     #'(lambda ()
        (for i 1 5
          (print "Step" i)
          (thread-yield)))) ;; передача управления на другие потоки

Ожидание завершения: ``thread-wait`` (пока не реализовано)
==========================================================

(thread-wait <id потока>)

Функция ``thread-wait`` приостанавливает вызывающий поток до тех
пор, пока не завершится поток с указанным id, и возвращает вычисленный
результат. В текущей реализации нельзя вызывать эту функцию в главном потоке.

Принудительная остановка: ``thread-kill``
=========================================

(thread-kill)
(thread-kill <id>)

Функция ``thread-kill`` прерывает выполнение текущего потока, если вызвана без параметров, или прерывает выполнения потока с указанным id.
