Драйвер протокола Ethernet
==========================

Драйвер обеспечивает передачу и приём кадров Ethernet.

Интерфейсы
----------

:ether-init pci: Инициализация сетвой карты с адресом pci. Возвращает объект ethernet.
:ether-read eth: Читает входящий пакет. Ждет прихода пакета. Возвращает массив байт.
:ether-set-out-MAC eth: Установить MAC адрес (массив из 6 байт), куда будет отправлен пакет.
:ether-write eth buf: Отправляет пакет. Данные берутся из массива байт buf.

Пример кода использования:
::

   ; обнаружили PCI сетевое устройство и записали в переменную pci
   (setq e1 (ether-init pci)) ; создаем объект устройства
   (setq buf (ether-read eth)) ; читаем входящий пакет
   (ether-set-out-MAC eth #(00 0x1A 0x2B 0x3C 0x4D 0x5E))
   (ether-write eth buf) ; отправили пакет
