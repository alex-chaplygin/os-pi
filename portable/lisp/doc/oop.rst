Система объектно-ориентированного программирования
--------------------------------------------------

**Класс** - абстракция нового типа объектов. Классы создаются динамически. При создании класса указывается родительский класс и список атрибутов. Если родительского класса нет, то указывается ().
::

     (defclass point () (x y)) ; создаем класс point с атрибутами x и y
     (defclass line point (x2 y2)) ; создаем класс line, который наследуется от point, и добавляем атрибуты x2 и y2

После создания класса автоматически создаются функции конструктора, селекторов (доступ к атрибутам), мутаторов (изменения атрибутов), предикат принадлежности:

:конструктор: (make-<имя класса> <атрибуты>), указываются значения всех атрибутов, включая из родительских классов, возвращает созданный объект
:селектор: (<имя класса>-<имя атрибута> <объект>), возвращает значение атрибута
:мутатор: (<имя класса>-set-<имя атрибута> <объект> <значение>), меняет значение атрибута
:предикат принадлежности: (<имя класса>p <объект>) возвращает истину если объект - экземпляр данного класса или его потомков
			  
::

   (setq p (make-point 1 2)) ; создаем объект точка x = 1, y = 2
   (point-x p) ; возвращает 1
   (point-set-x p 10); у объекта p x стало 10
   (setq l (make-line 2 3 10 11)) ; создать объект линия, x = 2, y = 3, x2 = 10, y2 = 11
   (pointp p) ; возвращает T
   (linep p) ; возвращает NIL

**Метод класса** - функция с динамической диспетчеризацией. В зависимости от типа объекта вызывается тот или иной метод. Первый параметр метода (<имя ссылки на объект> <класс>). По соглашению имя ссылки на объект всегда self. Методы добавляются в класс динамически.
::

   (defmethod move ((self point) dx dy) ; создать метод move для класса point
     (point-set-x self (+ (point-x self) dx))
     (point-set-y self (+ (point-y self) dy)))

   (defmethod move ((self line) dx dy) ; создать метод move для класса line
     (line-set-x self (+ (line-x self) dx))
     (line-set-y self (+ (line-y self) dy))
     (line-set-x2 self (+ (line-x2 self) dx))
     (line-set-y2 self (+ (line-y2 self) dy)))

   (move p 1 2) ; вызов метода move для точки
   (move l 1 2) ; вызов метода move для линии

Если необходимо вызывать метод родительского класса, используется оператор super:
::

   (super move l 1 2) ; для линии вызывается метод move из класса point

Для сокращения записи чтения всех полей можно использовать макрос with-slots, который создает блок локальных переменных, связанных с атрибутами объекта:
::
   (with-slot <имя класса> <список переменных> <объект>
       <тело блока>)

   ; вычисляем скалярное произведение между точками p и p2
   (with-slots point (x y) p ; в переменные x и y записываются значения атрибутов объекта p
     (with-slots point (x2 y2) p2
        (+ (* x x2) (* y y2))))
