Система времени выполнения
==========================

Система времени выполнения необходима для поддержки работы программы (интерпретатор или виртуальная машина).

Она состоит из системы распределения памяти и сборщика мусора.

Объекты системы представляют собой или непосредственное целое число или указатель на объект в памяти. Чтобы отличать эти объекты используется значение младших 2-х битов:
* 0 - указатель
* 1 - непосредственное целое число
* 3 - символ строки

0 выбрано для указателя, потому что это естественный вид указателя, не требующий модификаций, укзатели всегда выровнены по 4 (8) байт, то есть эти биты всегда будут равны нулю.

Объекты указатели это или записи с полями или строки. В начале каждого объекта лежит дескриптор, который хранит информацию объекте.

Дескриптор объекта
------------------

......length.......type
31(63)           4 3  0

Младшие 4 бита хранят тип объекта:
* BIGNUMBER - число которое не умещается в непосредственное
* FLOAT - число с плавающей точкой
* SYMBOL - символ
* PAIR - пара
* ARRAY - массив объектов
* BYTE_ARRAY - массив байт
* STRING - строка
* FUNCTION - функция

Биты с 4 по 31(63) хранят длину объекта (в байтах для массивов байт и строк, в полях для других структур)

Непосредственное целое число и строковые символы
------------------------------------------------

Это объекты, которые не участвуют в сборке мусора. 

.......................
31(63)              2 0

Число хранится с 2-го по 31(63)-й бит.

BIGNUMBER
---------

Одно поле - число

FLOAT
-----

Одно поле - число

SYMBOL
------

Поля:
* индекс в хеш-таблице
* указатель на объект - значение переменной    
* указатель на объект для функций (lambda выражение)
* указатель на объект для макроса
* указатель на функцию для примитивов
* список функций у метки
* данные об аргументах (младший бит: 0 - постоянное число аргументов, 1 - переменное, остальные биты - число аргументов или число обязательных аргументов)

PAIR
----

Поля:
* левый элемент (элемент списка)
* правый элемент (следующая пара)
* счетчик печати

Массив объектов
---------------

После дескриптора идут ячейки массива, одно поле - одна ячейка.

Массив байт
-----------

После дескриптора идут байты массива, количество байт из дескриптора, дополнены нулями до границы слова.


Строка
-------

После дескриптора идут байты строки, количество байт из дескриптора, дополнены нулями до границы слова.

Функция
-------

Поля:
* аргументы функции (число аргументов для примитива (фиксированных))
* тело функции (если 1 - то примитив с переменным числом аргументов)
* указатель на функцию примитив, если = NULL, то функция пользовательская, иначе встроенная
* окружение для переменных
* окружение для функций
